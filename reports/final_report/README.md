# 최종 보고서 자료 정리

**팀명**: 루메나  
**과제명**: 기상 및 발전 데이터를 활용한 대기오염물질 배출 최적화 모델 개발  
**부문**: 지정분석 / 에너지산업

---

## Ⅰ. 과제 개요 및 가설 (`1_개요및가설/`)

| 항목 | 내용 |
|------|------|
| 분석 배경 | 화력발전소 대기오염물질(SOx·NOx·먼지) 배출 규제 강화, 계절관리제 시행 |
| 핵심 가설 | "기상 대기정체 조건에서 발전 이용률을 최적화하면 NOx 배출을 15% 이상 감축할 수 있다" |
| 활용 데이터 | 한국남동발전 공공데이터포털 (배출농도·기상·발전실적·연료소비) + Open-Meteo 기상 API + 공공데이터포털 발전량 API |

> **준비 필요**: 배경 설명 텍스트, 가설 도식화

---

## Ⅱ. 분석 환경 및 데이터 (`2_데이터및환경/`)

### 분석 환경
- Python 3.10 / XGBoost 1.7.3 / scikit-learn 1.7.2 / SHAP 0.49.1
- 5개 사업소 독립 모델 구성

### 배출량 계산 공식
```
일 배출량(kg) = 농도(mg/Sm³) × 유량(Sm³/min) × 1,440(분/일) ÷ 1,000,000
```

### 먼지 모델 한계 설명
> 전기집진기(EP) 가동 중단 이벤트 발생 시 먼지 배출이 하루 만에 수십~수백 배 폭증.  
> SOx·발전량은 정상이나 먼지만 단독 폭증 → EP 운전 상태 피처 미확보로 예측 불가.  
> 구조적 한계로 명시.

## Ⅳ. 인사이트 및 해결책 (`4_인사이트/`)

### 핵심 결론
- 대기정체 시 삼천포 이용률 70%→50% 감발 → NOx **17% 감축**
- 영흥 이용률 83%→65% 감발 → NOx **25% 감축**
- 5사업소 연료 믹스 최적화 → 정상·황사 시나리오 시스템 NOx **15~16% 감축**

- 계절관리제(12~3월) 석탄발전 이용률 80% 상한 준수 근거 정량화
- EP 설비 이력 데이터 통합 시 먼지 예측 정확도 개선 가능
