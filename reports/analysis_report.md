## Ⅲ. 예측 모델링

### 3.1 모델 구조

- **알고리즘**: XGBoost MultiOutputRegressor (SOx·NOx·먼지 동시 예측)  
- **분할**: 시계열 순서 Train 80% / Validation 10% / Test 10% (랜덤 분할 금지)  
- **분당**: NOx 단독 예측 (SOx·먼지 ≈ 0이므로 제외)

### 3.2 모델 성능 (Test Set)

| 사업소 | 타겟 | R² | MAE (kg/day) |
|--------|------|----|:------------:|
| 삼천포 | SOx | **+0.737** | 1,111 |
| 삼천포 | NOx | **+0.400** | 2,476 |
| 삼천포 | 먼지 | -0.038 | 9,487 |
| 영흥 | SOx | **+0.620** | 1,220 |
| 영흥 | NOx | **+0.349** | 1,244 |
| 영흥 | 먼지 | -0.039 | 2,611 |
| 분당 | NOx | **+0.907** | 261 |

### 3.3 NOx 예측 성능 격차: LNG vs 석탄

분당(LNG) NOx R²=0.907 vs 삼천포·영흥(석탄) R²=0.35~0.40 의 격차 원인:

| 구분 | LNG (분당) | 유연탄 (삼천포·영흥) |
|------|-----------|-------------------|
| NOx 생성 메커니즘 | 연료량·연소온도에 비교적 선형 반응 | 화염 온도·산소 농도·연소 시간 복합 비선형 의존 |
| 운전 패턴 | 계통 수요에 따라 넓은 범위(0~96%) 가변 → 예측 신호 풍부 | 기저부하 고정 운전 → 이용률 변동폭 좁음, 배출량 변동이 노이즈에 묻힘 |
| 설비 구조 | 복합발전(가스터빈+증기터빈) — 배기 특성 상대적으로 안정 | 다수 호기(6기) 각기 다른 연소 상태 → 집계 배출량 변동성 높음 |
| 피처 품질 | 발전량(api_gen_mwh) 실측치 완전 | 발전량 일부 보간, 연료 소비 월별 균등 배분 |

> **결론**: 석탄 NOx R² 0.35~0.40은 데이터 한계 + 비선형 연소 물리의 복합 결과. 단일 변수 기반 예측 목적이 아닌 **상대적 비교·방향성 판단**에 활용.

**근본 원인**: 측정 이상치의 구조적 지배

| 항목 | 삼천포 | 영흥 |

## Ⅵ. 시스템 레벨 연료 믹스 최적화

### 6.1 분석 설계

단일 사업소 이용률 최적화를 넘어, **3사업소 동시 배분 최적화**를 수행했습니다.

- **결정 변수**: 삼천포 이용률(12단계) × 영흥 이용률(7단계) = 최대 84 조합  
- **분당 발전량**: 총수요 - 삼천포 - 영흥으로 역산 (용량 상한 제약)  
- **목적함수**: 총 사회적 비용 최소화  
  `min: SOx×500 + NOx×2,130 + 먼지×770 (원/kg)`  
  (환경부 대기배출부과금 고시 기준 단가 적용)
- **총 기준 수요**: 102,705 MWh/일 (3사업소 현재 평균 합산)

### 6.2 사회적 비용 단가 (환경부 대기배출부과금 기준)

| 오염물질 | 적용 단가 | 근거 |
|----------|:--------:|------|
| SOx | **500 원/kg** | 환경부 대기배출부과금 고시 (2018년 이후) |
| NOx | **2,130 원/kg** | 동일 |
| 먼지 (PM) | **770 원/kg** | 동일 |

> 대기배출부과금은 오염물질 배출에 대해 법적으로 부과되는 최소 사회적 비용으로, 실제 건강 피해 기반 외부비용(KEI 추정)은 이보다 높을 수 있음.

### 6.6 열효율 vs 배출 상충 관계 (핵심 발견)

```
[현재 운영]
  삼천포 52.7% → 열효율 31.0% (이용률↑→효율↑, 삼천포 특성)
  영흥   82.8% → 열효율 27.3% (이용률↑→효율↓, 영흥 기저부하 특성)

[최적 배분 (시나리오 A)]
  삼천포 36.0% → 열효율 25.8% (-5.2%p 악화)
  영흥   94.0% → 열효율 24.4% (-2.9%p 악화)

```
