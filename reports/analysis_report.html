3.3 NOx 예측 성능 격차: LNG vs 석탄

분당(LNG) NOx R²=0.907 vs 삼천포·영흥(석탄) R²=0.35~0.40 의 격차 원인:

구분 LNG (분당) 유연탄 (삼천포·영흥)
NOx 생성 메커니즘 연료량·연소온도에 비교적 선형 반응 화염 온도·산소 농도·연소 시간 복합 비선형 의존
운전 패턴 계통 수요에 따라 넓은 범위(0~96%) 가변 → 예측 신호 풍부 기저부하 고정 운전 → 이용률 변동폭 좁음, 배출량 변동이 노이즈에 묻힘
설비 구조 복합발전(가스터빈+증기터빈) — 배기 특성 상대적으로 안정 다수 호기(6기) 각기 다른 연소 상태 → 집계 배출량 변동성 높음
피처 품질 발전량(api_gen_mwh) 실측치 완전 발전량 일부 보간, 연료 소비 월별 균등 배분

결론: 석탄 NOx R² 0.35~0.40은 데이터 한계 + 비선형 연소 물리의 복합 결과. 단일 변수 기반 예측 목적이 아닌 상대적 비교·방향성 판단에 활용.

6.1 분석 설계

단일 사업소 이용률 최적화를 넘어, 3사업소 동시 배분 최적화를 수행했습니다.

  • 분당 발전량: 총수요 - 삼천포 - 영흥으로 역산 (용량 상한 제약)
  • 목적함수: 총 사회적 비용 최소화
    min: SOx×500 + NOx×2,130 + 먼지×770 (원/kg)
    (환경부 대기배출부과금 고시 기준 단가 적용)
  • 총 기준 수요: 102,705 MWh/일 (3사업소 현재 평균 합산)

7.2 정책 권고

단기 (즉시 적용 가능)

  1. 여름 대기정체일 (대기정체지수 > 34, 기온 > 27°C, 풍속 < 2 m/s):
    삼천포 이용률 36% 감발, 영흥 94% 증발 → NOx 12% 감축 (대체 비용 없는 내부 재배분)
  2. 계절관리제 기간 (12~3월): 삼천포 35%, 영흥 80% 배분 + 분당 LNG 보완 → NOx 8.9% 감축
  3. 적용 우선순위: 신재생 잉여 발전 시간대에 감발 적용 시 대체 비용 최소화

중기 (시스템 구축 필요)

  1. 실시간 배분 최적화 시스템: 전날 기상 예보 기반으로 3사업소 발전 배분 사전 계획
  2. 먼지 측정 이상치 필터링: 설비 점검·시동 이벤트를 별도 플래그로 관리하여 예측 정확도 향상

장기 (제도·설비 개선)

  1. 신재생 확대 연계: 영흥 풍력(53 MWh/일) 증설 시 석탄 감발 여력 확보
  2. 분당 연료전지 활용: 대기정체일 분당 연료전지(현 586 MWh/일) 우선 가동으로 석탄 대체
